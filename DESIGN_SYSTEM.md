# 🎨 Дизайн-система Соседик

## Типографика

### Используемые шрифты:

1. **Inter** — основной шрифт (body текст, контент)
   - Вес: 400, 500, 600, 700
   - Используется для всех основных текстов
   - Чистый, современный, хорошо читаемый

2. **Plus Jakarta Sans** — заголовки и акценты
   - Вес: 500, 600, 700
   - Используется для h1-h6, логотипа
   - Смелый, стильный, привлекает внимание

3. **Poppins** — вспомогательный шрифт для UI элементов
   - Вес: 400, 500, 600, 700
   - Используется для кнопок, меню, модальных окон
   - Дружелюбный, современный, хорошо смотрится на кнопках

### Применение:

```css
body {
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
}

h1, h2, h3, h4, h5, h6,
.logo {
  font-family: 'Plus Jakarta Sans', sans-serif;
}

button,
.btn-primary,
.btn-secondary,
.btn-danger,
.btn-success,
.btn-ghost {
  font-family: 'Poppins', 'Inter', sans-serif;
}
```

## Система кнопок

### Классы кнопок:

#### 1. Первичные кнопки (`.btn-primary`)
Для основных действий
```html
<button class="btn-primary">Действие</button>
```
- Цвет: Фиолетово-розовый градиент (#667eea → #764ba2)
- Текст: Белый
- Использование: Главные действия, отправка форм

#### 2. Вторичные кнопки (`.btn-secondary`)
Для вспомогательных действий
```html
<button class="btn-secondary">Отмена</button>
```
- Цвет: Светло-серый фон
- Текст: Тёмно-серый
- Использование: Возвраты, отмены, второстепенные действия

#### 3. Опасные кнопки (`.btn-danger`)
Для критических действий
```html
<button class="btn-danger">Удалить</button>
```
- Цвет: Белый фон с красной границей
- Текст: Красный
- Использование: Удаление, отключение, опасные операции

#### 4. Успешные кнопки (`.btn-success`)
Для позитивных действий
```html
<button class="btn-success">Сохранить</button>
```
- Цвет: Зелёный градиент (#00d084 → #00b86c)
- Текст: Белый
- Использование: Подтверждение, сохранение, успешные операции

#### 5. Призрачные кнопки (`.btn-ghost`)
Для минималистичных действий
```html
<button class="btn-ghost">Подробнее</button>
```
- Цвет: Прозрачный фон
- Текст: Серый
- Использование: Дополнительные опции, ссылки

### Размеры кнопок:

- `.btn-sm` — маленькие (6px 12px)
- Стандартные (10px 20px)
- `.btn-lg` — большие (14px 32px)

### Дополнительные классы:

- `.btn-with-icon` — для кнопок с иконками
- `.btn-block` — полная ширина

### Примеры использования:

```html
<!-- Стандартная первичная кнопка -->
<button class="btn-primary">Отправить</button>

<!-- Маленькая вторичная кнопка -->
<button class="btn-sm btn-secondary">Отмена</button>

<!-- Большая кнопка успеха с иконкой -->
<button class="btn-lg btn-success btn-with-icon">
  <svg width="16" height="16">...</svg>
  Сохранить
</button>

<!-- Опасная кнопка -->
<button class="btn-danger">Удалить аккаунт</button>

<!-- Полная ширина -->
<button class="btn-primary btn-block">Войти</button>
```

## Эффекты и переходы

Все кнопки используют плавные переходы (0.3s ease):
- **Hover**: Поднятие на 2px, тень
- **Active**: Сжатие (scale 0.98)
- **Disabled**: Прозрачность 60%, без интерактивности
